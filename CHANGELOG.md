# PokeEssentialsAccess 0.2.0

- Añadido un glosario de sonidos para familiarizarte con el mod. Este está en el menú de configuración
  del mod.
- Mejorado el menú para remapear las teclas del mod, ahora se pueden remapear más teclas y se evitan
  fallos al duplicar entradas.
- Añadido soporte inicial para Pokémon Infinite Fusion y Pokémon Infinite Fusion 2.
- Mejorado el mapa de vuelo, ahora puedes utilizar las teclas del pathfinder para encontrar los puntos
  de vuelo permitidos de forma más rápida.
- Refactorizado el mod internamente para soportar plugins comunes a juegos.
- Arregladas múltiples pantallas inaccesibles.
- Ahora el buscador de superficies llega más lejos y utiliza internamente el pathfinder para guiarte
  más lejos.
- Se ha subido el límite máximo del sonar de 20 a 30.
- Mejorado internamente el mod para facilitar la accesibilización de pantallas y minijuegos.
- Mejorado el rendimiento general.
